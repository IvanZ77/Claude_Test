# 上海生活计算器

一个面向海外华人的资产-生活映射工具。

## 功能介绍

这个工具帮助海外华人规划移居上海，通过以下方式：

- **资产转换**：基于美国 4% 安全提取率（The 4% Rule），将你的可投资资产换算为上海月度可支配收入
- **生活方式对标**：匹配六档不同的生活方式等级，包含：
  - 真实小区参考
  - 国际学校选项
  - 推荐餐厅地点
  - 日常消费估算

## 使用方法

1. 打开应用：[上海生活计算器](https://IvanZ77.github.io/Claude_Test/)
2. 拖动滑块输入你的可投资资产总额（以美元计）
3. 实时查看对应的月度可支配收入和生活方式画像
4. 浏览具体的小区、学校、餐厅推荐

## 核心概念

### 4% 安全提取率
基于研究表明，投资者可以从投资组合中每年安全地提取初始投资的 4%，而不会因通胀而耗尽资金。

**计算公式**：
```
月度可支配收入 = 投资资产总额 × 4% ÷ 12
```
