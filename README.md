# 多城市生活成本计算器

一个直观的资产-生活方式映射工具，帮助你理解在不同城市生活所需的成本。基于**4% 安全提取率**，将你的可投资资产换算为月度可支配收入，匹配真实的生活档位。

**[在线使用](https://IvanZ77.github.io/shanghai_life_calculator)** 

---

## 核心功能

✅ **资产转换为月度生活费** — 自动计算你能过什么样的生活  
✅ **21 个城市，8 个国家** — 中国、日本、泰国、美国、越南、英国、法国、中国香港  
✅ **6 个生活档位** — 从拮据到顶奢，每档包含真实小区、学校、餐厅  
✅ **多城市并排对比** — 同样资产在不同城市的生活差异  
✅ **FIRE 计算器** — 计算财务自由所需资产和达成年限  
✅ **灵活参数调整** — 自定义税率、汇率、收益率等  
✅ **URL 分享** — 将你的配置编码到链接，与朋友分享  
✅ **深色模式 + 响应式** — 手机、平板、电脑完美适配

### 3️⃣ 调整参数（进阶）

#### 为什么调整参数？
计算器使用默认假设：4% 提取率、20% 投资税、6.8 汇率。但这些数字取决于你的具体情况。

#### 可调整的参数
- **提取率** — 默认 4%（Trinity Study），范围 2.5%-6%
- **投资税率** — 默认 20%（美国长期资本利得税），范围 0%-45%
- **USD↔CNY 汇率** — 默认 6.8，范围 5.0-8.5
- **年化收益率** — 默认 7%（历史股票平均），范围 0%-15%
- **通胀率** — 默认 2.5%，范围 0%-10%

#### 修改方法
1. 点击 **"调整参数"** 折叠框展开
2. 用滑块或数字输入框修改
3. 结果实时更新
4. 点 **"重置为默认值"** 恢复原设置

#### 参数对结果的影响示例
- 提取率 4% → 3.5%：同样资产能支配的月度收入减少 12.5%
- 汇率 6.8 → 7.0：月度人民币收入增加 2.9%
- 投资税 20% → 15%：年提取额增加 6.25%

### 4️⃣ FIRE 计算器（财务自由规划）

#### FIRE 是什么？
**FIRE**（Financial Independence, Retire Early）= 财务自由。当你的资产产生的被动收入 ≥ 年度支出时，你就可以不工作而维持生活。

#### 如何使用
进入计算器后，在 **"FIRE 计算器"** 部分输入：
- **当前资产** — 你现在有多少钱
- **每月储蓄** — 你每个月能存多少
- **年化收益率** — 投资回报率（默认 7%）
- **通胀率** — 生活成本上升速度

#### 计算器输出
1. **FIRE 目标资产** — 你需要积累多少钱才能财务自由
2. **距离目标还需 X 年** — 根据储蓄速度和投资回报计算
3. **资产增长曲线** — 图表显示达成过程（考虑通胀）
4. **Coast FIRE** — "仅靠复利"就能达成的最低本金

#### 实例
如果年支出 30 万元（月支出 2.5 万）：
- FIRE 目标 = 30 万 ÷ 4% = 750 万元
- 如果当前有 200 万，年存 20 万，年回报 7%，大约 8 年达成

## 计算原理 📐

### 月度可支配收入如何计算？

#### 公式

```
第1步：年度提取
  年提取(美元) = 资产 × 提取率
  
  例：资产 100 万美元 × 4% = 4 万美元/年

第2步：缴税
  税后(美元) = 年提取 × (1 - 税率)
  
  例：4 万 × (1 - 20%) = 3.2 万美元/年

第3步：换算月度
  月度(美元) = 税后 ÷ 12
  
  例：3.2 万 ÷ 12 ≈ 2667 美元/月

第4步：转换人民币
  月度(人民币) = 月度(美元) × 汇率
  
  例：2667 × 6.8 ≈ 18,136 元/月
```

#### 为什么用 4% 提取率？

**4% 规则**来自著名的 **Trinity Study**（美国三一大学研究）：
- 研究了 100 年的美股历史数据
- 发现每年提取初始资产的 4%，在 30 年的退休期内，资金不会用完的概率 ≥ 95%
- 假设资产投资于股票和债券，年均回报 7%-10%

### 生活档位如何匹配？

根据你的 **月度人民币收入** 自动匹配一个档位：

```
收入 < 6,000 元       → 拮据生活
6,000-12,000        → 基本小康
12,000-25,000       → 舒适生活
25,000-55,000       → 品质生活
55,000-120,000      → 豪华生活
120,000+            → 顶奢生活
```

### 每个档位的支出如何分配？

计算器根据 **真实市场数据** 估算每个档位的预算分配，7 个类别的百分比加总为 100%：

```
例：舒适生活档位（月支出 2.5 万）的预算分配

住房/租金   30% → 7,500 元/月
教育        20% → 5,000 元/月
餐饮        14% → 3,500 元/月
交通        10% → 2,500 元/月
医疗        6%  → 1,500 元/月
旅行        12% → 3,000 元/月
购物        8%  → 2,000 元/月
───────────────────
合计        100% → 25,000 元/月
```

这些数据是基于 2025-2026 年市场实际调查。

### FIRE 达成年限如何计算？

假设你：
- 当前资产 PV 元
- 每年储蓄 PMT 元
- 年化收益率 r
- FIRE 目标 FV 元

达成年限的闭式解为：

```
实际收益率 = (1 + 名义收益率) / (1 + 通胀率) - 1

n = ln((FV·r + PMT) / (PV·r + PMT)) / ln(1 + r)

n = 达成所需年数
```

#### 简化理解
- 资产每年以 r% 增长
- 加上每年新增的储蓄 PMT
- 直到总资产达到 FV

## 核心假设 ℹ️

计算器基于以下假设。**请注意这些假设可能与你的实际情况有差异**：

| 假设 | 默认值 | 说明 |
|-----|-------|------|
| **安全提取率** | 4% | 基于 Trinity Study，30 年退休期，95% 成功率 |
| **美国投资税** | 20% | 长期资本利得税（联邦），不含州税，简化估算 |
| **USD↔CNY 汇率** | 6.8 | 参考央行中间价，实际波动可调整 |
| **家庭模型** | 2 大 1 小 | 两位成人 + 一名学龄儿童 |
| **年化收益率** | 7% | 美股历史平均，个人投资可能不同 |
| **通胀率** | 2.5% | 中长期平均，实际变动可调整 |

### 数据来源与更新频率

- **房产数据** — 链家、贝壳找房（二手房成交价）
- **学费数据** — 国际学校官方网站、招生部门
- **餐饮数据** — 大众点评、小红书、本地论坛
- **更新频率** — 每 6-12 个月核对一次，有明显变动时及时更新

## 常见问题 ❓

**Q: 这个计算器很准确吗？**  
A: 这是一个「参考工具」，不是「精确预测」。实际生活成本因人而异：
- 同样月收入，有人奢侈有人节俭
- 房价、学费、汇率都在变动
- 个人税率可能高于 20%（州税、医疗税）

**建议**：用这个工具做粗略估算，再找当地人了解具体成本。

---

**Q: 能离线使用吗？**  
A: 可以。这是一个纯前端应用，下载源码后用浏览器打开，完全离线运行。

---

**Q: 为什么有这么多城市？**  
A: 为了帮助不同背景的用户（居住、移居、投资考察）进行生活成本比较。每个城市数据都基于真实市场调查。

---

**Q: 可以修改某城市的数据吗？**  
A: 如果你发现数据明显过时或错误，欢迎提交反馈（GitHub Issues）。

---

**Q: 支持跨国城市对比吗（如上海 vs 伦敦）？**  
A: 支持。计算器统一用 CNY 计价，跨国城市自动按汇率转换。但要注意：
- 生活成本结构不同（如欧洲免费教育不同）
- 税率差异大
- 货币波动影响
